ICD-11 TM1 minimum data set dashboard

ICD-11 now includes traditional medicine, but few countries collect routine data on it yet. This dashboard helps each Member State see where it stands and what it can already report, so that the Region can build comparable traditional medicine data, step by step.

What you can see here

1Readiness

How ready each country is to produce ICD-11 TM1 data. Five simple criteria place it in type A (data-ready), B (partially ready) or C (emerging).

2Data available now

Which items of the minimum data set (MDS), the short list of data all countries work towards, each country can report today, and where the gaps are.

3Indicators and progress

Six aggregate indicators, each with its source, coverage and coding method, and how countries move forward year by year.
